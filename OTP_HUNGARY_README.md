# OTP Bank Hungary - Interactive CLI Authentication

This interactive CLI script helps you authenticate with your OTP Bank Hungary personal account using the Enable Banking API. The script provides step-by-step guidance and prompts to make the authentication process as smooth as possible.

## Features

- 🎯 **Interactive prompts** - Guides you through each step of the process
- 📝 **Detailed instructions** - Explains how to obtain all required credentials
- ✅ **Validation** - Verifies each step before proceeding
- 💾 **Config management** - Option to save configuration for future use
- 🏦 **Account information** - Displays balances and recent transactions after authentication
- 🔒 **Secure** - Uses JWT tokens and follows Enable Banking security best practices

## Prerequisites

Before running this script, you need:

1. **Python 3.6 or higher** installed on your system
2. **OTP Bank Hungary online banking account** with active credentials
3. **Enable Banking developer account** (the script will guide you through creating one)

## Detailed Setup Guide

If you prefer to set up credentials before running the script, follow these steps:

### Step 1: Create Enable Banking Developer Account

1. Visit [Enable Banking](https://enablebanking.com/)
2. Click **"Get started"** to create a developer account
3. Complete the registration form
4. Verify your email address

### Step 2: Register Your Application

1. Log in to [Enable Banking Control Panel](https://enablebanking.com/cp/applications)
2. Click **"New Application"** or **"Register Application"**
3. Fill in the application details:
   - **Name**: Choose any name (e.g., "OTP Hungary CLI Tool")
   - **Redirect URL**: `http://localhost:8080/auth_redirect`
4. Click **"Generate Key"** or similar option
5. Choose **"Generate in browser"** when prompted
6. Download the `.pem` private key file
   - It will be named with your Application ID (a UUID)
   - Example: `0377783c-3414-4bb1-a7d4-0c3eb54cd4b0.pem`
7. Save your **Application ID** (the UUID)

### Step 3: Prepare Configuration

Create a `config.json` file in the same directory as the script:

```json
{
    "applicationId": "YOUR-APPLICATION-ID-HERE",
    "keyPath": "YOUR-APPLICATION-ID-HERE.pem",
    "redirectUrl": "http://localhost:8080/auth_redirect"
}
```

Replace `YOUR-APPLICATION-ID-HERE` with your actual Application ID.

### Step 4: Place Your Private Key

Move the downloaded `.pem` file to the same directory as the script.

3. ✅ Guide you through obtaining your credentials

### Subsequent Runs (Using Saved Config)


When prompted "Do you have a config.json file already set up?", type **`y`**.

## Authentication Flow

The script will guide you through these steps:

### 1. Configuration Setup
- Load existing config or create new one

### 2. Create Authentication Token
- Generate JWT token using your private key

### 3. Verify Application
- Confirm your credentials with Enable Banking API

### 4. Start Authorization
- Initiate authorization with OTP Bank Hungary

### 5. Complete Authentication
The script will display a URL for you to visit:

```
1. Open this URL in your web browser:
   https://api.enablebanking.com/auth/...

2. You will be redirected to OTP Bank Hungary's login page
   → Enter your online banking credentials
   → You may need to provide an OTP (One-Time Password)
   → The OTP is typically sent via SMS or generated by your token device
   → Follow the bank's authentication steps

3. After successful authentication, you will be redirected
   → Copy the ENTIRE URL from your browser's address bar
   → It should look like: http://localhost:8080/auth_redirect?code=...

4. Paste the URL back into the script when prompted
```

### 6. View Account Information
- See your account balances
- View recent transactions (last 30 days)
- Get your session ID for future API calls

## OTP (One-Time Password) Information

OTP Bank Hungary may require an OTP during authentication. Here's how to get it:

### SMS OTP
- OTP Bank will send a text message to your registered mobile number
- Enter the code when prompted during the authentication process
- The code is typically 6 digits and valid for a few minutes

### Hardware Token
- If you have an OTP hardware token from the bank, use it to generate a code
- Press the button on the token to generate a new code
- Enter the code when prompted

### Mobile App
- If you use OTP Bank's mobile banking app, you may receive a push notification
- Approve the transaction in the app
- Or use the app to generate an OTP code

## Troubleshooting

### "Private key file not found"

**Problem**: The script can't find your `.pem` file

**Solutions**:
- Make sure the `.pem` file is in the same directory as the script
- Check that the filename matches what's in your config
- Use absolute path in config: `/full/path/to/your-app-id.pem`

### "Failed to verify application"

**Problem**: Application credentials are invalid

**Solutions**:
- Verify your Application ID is correct (check Enable Banking portal)
- Ensure the `.pem` file matches your application
- Check that your application is active in the Enable Banking portal
- Make sure you're using the correct private key file

### "No 'code' parameter found in the URL"

**Problem**: The redirect URL doesn't contain the authorization code

**Solutions**:
- Make sure you completed the bank authentication successfully
- Copy the **entire** URL from the browser, not just part of it
- Check that you're copying from the address bar after the redirect
- The URL should start with `http://localhost:8080/auth_redirect?code=...`

### "Failed to create session"

**Problem**: The authorization code is invalid or expired

**Solutions**:
- Authorization codes are single-use and expire quickly
- Start the process again and complete it without delays
- Make sure you're copying the redirect URL immediately after authentication

### Browser shows "This site can't be reached"

**Problem**: After bank authentication, browser shows an error

**Solution**: This is **NORMAL**! You don't need a server running. Just copy the URL from the address bar - that's all you need.

## Security Notes

🔒 **Keep your credentials secure**:
- Never share your `.pem` private key file
- Never commit your `config.json` to version control
- Keep your Application ID confidential
- The `.pem` file gives full access to your Enable Banking application

🔐 **Session security**:
- Sessions created by this script have 90-day validity
- Store session IDs securely if you plan to reuse them
- Never share your session ID with others
